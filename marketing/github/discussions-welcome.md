# 👋 Welcome to slash-editor Discussions

Category: Announcements (pinned)

Thanks for stopping by. Use these categories:

- **Q&A**: "how do I…", integration questions. Mark the answer that solved your problem.
- **Ideas**: new blocks and API changes. Please describe the use case, not only the feature.
- **Show and tell**: share what you built with slash-editor. We'll feature projects in the
  README and on the site.
- **Bugs**: open an [issue](https://github.com/buiducnhat/slash-editor/issues/new/choose)
  instead, with a reproduction from the playground if you can.

**Where things are going:** 0.x is about getting the API right before 1.0. If a hook or option
felt awkward, that's exactly the feedback we want. Reply here or open an Idea.

**Contributing:** start with [CONTRIBUTING.md](../blob/main/CONTRIBUTING.md) and the
[good first issues](https://github.com/buiducnhat/slash-editor/labels/good%20first%20issue).

Introduce yourself below: what are you building, and what editor were you using before?
