# Getting Help / Support

## Questions

For questions about using slash-editor:

- **GitHub Discussions** — [Open a discussion](https://github.com/buiducnhat/slash-editor/discussions)
  for usage questions, ideas, or general conversation.
- **GitHub Issues** — [Open an issue](https://github.com/buiducnhat/slash-editor/issues/new?template=question.yml)
  using the question template for specific technical questions.

## Tiptap / ProseMirror

slash-editor is built on [Tiptap](https://tiptap.dev) and [ProseMirror](https://prosemirror.net/).
For engine-level questions:

- [Tiptap documentation](https://tiptap.dev/docs)
- [ProseMirror documentation](https://prosemirror.net/docs/guide/)
- [Tiptap GitHub Discussions](https://github.com/ueberdosis/tiptap/discussions)
