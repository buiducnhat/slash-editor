## Usage

Enable the `emoji` extension in the block kit and render the menu next to the editor:

```tsx
useSlashEditor({ blockKit: { emoji: {} } });

<EmojiMenu editor={editor} />;
```

Type `:` followed by a name (`:rocket`) to open the picker, or choose **Emoji** from the slash
menu. Completing a `:shortcode:` by hand also inserts the emoji. See the
[emoji guide](/docs/guides/emoji).
