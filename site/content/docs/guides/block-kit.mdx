## Opting a block out for a custom NodeView

A host that needs a real `NodeView` (React, Vue, …) opts the baseline node out and supplies its
own via `extend`, keeping a single schema registration:

```tsx
import { Image } from "@slash-editor/core";
import { ReactNodeViewRenderer } from "@tiptap/react";
import { ImageNodeView } from "@/components/nodes/image-node-view";

useSlashEditor({
  blockKit: {
    image: false,
    extend: [Image.extend({ addNodeView: () => ReactNodeViewRenderer(ImageNodeView) })],
  },
});
```

The [Media & AI Node Views](/docs/components/node-views) component ships exactly this pattern —
`adapter` is always a prop, never a hardcoded mock.

## Configuring StarterKit

The kit builds on Tiptap's `StarterKit`. `starterKit` forwards options to it for the extensions
the kit leaves alone — drop the underline mark (with its `Mod-u` shortcut and `++text++`
markdown), restyle the drop cursor, configure hard breaks:

```tsx
useSlashEditor({
  blockKit: {
    starterKit: { underline: false, dropcursor: { color: "var(--primary)" } },
  },
});
```

Keys the kit owns are not accepted, so each setting has one place to live: `heading` is
`headingLevels`, `undoRedo` is `history` (and `collaboration`), `link` and `codeBlock` are the kit's
own options. `blockquote` stays off because `Quote` registers its own `blockquote` node, and
`gapcursor` stays off so clicks in block margins focus the nearest text.

Slash items, block types, and bubble toolbar buttons hide themselves when their node or mark is
missing, so `starterKit: { bulletList: false }` simply drops "Bulleted list". Disabling a node
other nodes' content requires — `listItem` while `bulletList`/`orderedList` stay on, or
`paragraph` — throws a schema error.

## No-default options

`mention`, `ai`, and `collaboration` have no default provider/adapter, so they stay unregistered
until you pass one — see the [mentions](/docs/guides/mentions),
[AI stream adapter](/docs/guides/ai-stream-adapter), and
[collaboration](/docs/guides/collaboration) guides.

`emoji` is opt-in for a different reason: its dataset is sizeable, and enabling it converts typed
`:shortcode:` text into emoji nodes. Pass `emoji: {}` to enable it — see the
[emoji guide](/docs/guides/emoji).

`codeBlock` is opt-in too. Left out, StarterKit's plain code block is used; `codeBlock: {}` swaps it
for a syntax-highlighted one (lowlight) of the same name. Pass your own `lowlight` instance to choose
the grammars, or see [Code Block Node View](/docs/components/code-block-node-view) for the language
selector and token theme.
