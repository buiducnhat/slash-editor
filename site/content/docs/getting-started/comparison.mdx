Every editor here is good software; the right pick depends on the engine you want, how you want
UI delivered, and which features you need under an open-source license. Facts below were checked
against each project's pricing page, LICENSE, and npm registry on 2026-09-29 — verify before
relying on them, since pricing and packaging change.

## When slash-editor fits

- You want Notion-style block UX on **Tiptap/ProseMirror**, with any Tiptap extension still
  working because the document stays plain Tiptap JSON.
- You want the rendered UI as **source in your repo**, styled by your shadcn tokens.
- You need collaboration, comments, and AI **without a commercial license or hosted service** —
  each backend piece is an adapter you implement.

## When something else may fit better

- **Vue or other frameworks today:** Tiptap supports them directly; slash-editor's UI and hooks
  are React-only (the core has no React dependency).
- **You prefer Slate:** Plate is MIT, mature, and also ships a shadcn registry.
- **You want batteries-included styled components** and a larger community: BlockNote.
- **A hosted collaboration/AI backend** you don't run yourself: Tiptap's platform.
